# MDATA Experiment Code and Results (Lightweight Release)

This is the lightweight GitHub release of the actual experiment directory used
for the MDATA paper. It preserves the code, experiment results, user-study
materials, and dataset metadata. Bulky dataset payloads are omitted so that the
ZIP archive remains below GitHub's 25 MB web-upload limit.

## Included contents

- `code/`: Algorithms, data generation, baselines, evaluation, and result
  generation scripts used in the paper's experiments.
- `results/`: The experiment result files in JSON/NPZ format corresponding to
  the paper. No result files have been removed from this lightweight release.
- `user_study/`: Generated user-study cases, protocol, and response sheet.
- `data/mega_bench/index.json`: Scale, seed, record counts, original compressed
  sizes, and SHA-256 hashes for the twelve generated MEGA-Bench datasets.
- `data/mega_bench/validation.json`: Cross-checks of record and behaviour
  counts against the experiment results.
- `data/theia_raw_manifest.txt`: Names of the raw files used in the full THEIA
  experiments.
- `requirements*.txt`: Python dependencies.
- `run_all.sh`: The experiment execution sequence.
- `FILE_MANIFEST.sha256`: Integrity checksums for files included in this
  lightweight release.

## Dataset 1: MEGA-Bench (generated locally)

MEGA-Bench is a semi-synthetic benchmark generated by this repository, not a
third-party dataset that needs to be downloaded. The large serialized files
`data/mega_bench/*.json.gz` are omitted from this release.

The experiment scripts call `datagen.generate(seed, scale)` directly, so these
serialized copies are not required for the standard rerun path. The generator
is deterministic for a given scale and seed. The metadata files retain the
specifications and hashes of the original twelve datasets:

- S1 and S2: seeds 11, 22, 33, 44, and 55.
- S3 and S4: seed 11.

Each generated dataset contains `records`, `behaviors`, `campaigns`, and
`world`. See `code/datagen.py` and `code/config.py` for the generation logic,
scale parameters, and random-seed configuration.

## Dataset 2: DARPA TC E3 THEIA (public download)

THEIA is a public third-party dataset. Neither its raw data nor the derived
compact cache `data/theia_sample_compact/` is included in this lightweight
release.

Official dataset resources:

1. DARPA Transparent Computing Engagement 3 release description and manifest:
   https://github.com/darpa-i2o/Transparent-Computing/blob/master/README-E3.md
2. Official Five Directions Google Drive folder linked by that DARPA manifest:
   https://drive.google.com/open?id=1QlbUFWAGq3Hpl8wVdzOdIoZLFxkII4EK
3. PIDSMaker preprocessing repository:
   https://github.com/ubc-provenance/PIDSMaker
4. PIDSMaker dataset documentation:
   https://ubc-provenance.github.io/PIDSMaker/datasets/

The THEIA files used by the full experiments are listed in
`data/theia_raw_manifest.txt`. The principal archives are
`ta1-theia-e3-official-1r.json.tar.gz` and
`ta1-theia-e3-official-6r.json.tar.gz`; the sample experiment also uses THEIA
E3 official data file 3. After downloading the data, follow the preprocessing
and execution notes in `code/README_DARPA_TC.md` and the parsing scripts in
`code/`.

## Reproduction notes

Create a virtual environment, install `requirements.txt`, and use the entry
points in `run_all.sh` to rerun the experiments. GPU-specific stages have
separate dependencies in `requirements-gpu.txt`. THEIA-specific dependencies
are listed in `requirements-theia.txt`.

The supplied `results/` directory allows the reported numbers and derived
analyses to be inspected without downloading or regenerating the large input
datasets.

## Data exclusions and confidentiality

No confidential operational records from the real security-assurance operation
are included, and such records must not be uploaded. MEGA-Bench uses only
anonymised aggregate statistics for calibration; every exported MEGA-Bench
record is synthetic.

The code directory contains no `llm_api.json`, logs, caches, or API keys.
